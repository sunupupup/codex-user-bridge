# 本地聊天测试页

用户已确认简单版本：网页显示问题、手动回复，保留自动模拟模式。

- 新增 `local_chat` 渠道，默认启动入口改为此渠道；`local_mock` 仍可显式开启自动回复。
- 原生 HTML/CSS/JavaScript，无前端构建依赖；同一个本地 HTTP 服务提供页面、问题列表和回复接口。
- 页面按问题显示气泡、候选答案与回复框，每两秒查询最新状态。已有回答不可覆盖，刷新保留数据库记录。
- MCP 两个工具不变，增加 local_chat 来源。手动回答不标为自动模拟，但仅代表本机浏览器输入，不声称验证了远端用户身份。
- UI 接口只用于 local_chat；严格校验 Host、同源 Origin 和 JSON，文本通过 textContent 渲染。

实施顺序：存储与 HTTP → 页面与打包 → MCP 来源与说明 → 回归测试及浏览器实测。
验收：两个问题不串答、重复回答不覆盖、跨域请求被拒绝、刷新后状态保留、MCP 可查询网页提交的回答。
