# 原生提问回填实验

用户已确认：同一问题编号关联两个答案入口，后台收到答案后完成原请求。

## 范围

先复用 localhost:5555 local_chat 页面，启动独立 Codex App Server，
接收真实 item/tool/requestUserInput 并用原 JSON-RPC id 返回答案。
这是协议接入实验，不代表已接管桌面版现有连接，不安装全局 Hook。

选择此方式，是因为当前桌面进程使用 stdio，尚未发现公开的附加连接入口。
Hook 可作为后续观察入口，但仅观察事件不能替代响应传输。

## 实施和验证

1. 新增独立实验脚本，调用本机 codex，不修改插件工具契约。
2. 新建隔离的临时会话，只提问，不执行工作区操作。
3. 原 RPC id、问题 id、本地 bridge id 分别保存映射，禁止混用。
4. local_chat 回复后返回 answers；收到 resolved 时删除等待，避免晚到回复。
5. 总时限到达或异常时关闭实验进程；不重连重放答案。
6. 自动验证使用明确标注的测试文本，不能当作真人授权。
